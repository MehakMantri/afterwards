# Afterwards

Free, private help with the paperwork after a death in the family, for India.

Answer a few plain questions and get the right claim forms, filled in, for each
bank or institution. Every rule links to its official source. Nothing you type
leaves your browser.

Built for Kiroween 2026 (Skeleton Crew): one engine, two apps.

## Layout

| Folder | What it is |
|---|---|
| `engine/` | The skeleton: question flow, rule evaluator, PDF filler, tracker |
| `apps/afterwards/` | App 1: claims after a death (bank forms under the RBI 2025 Directions) |
| `apps/turning-18/` | App 2: paperwork when a child becomes an adult |
| `.kiro/` | Kiro specs, steering and hooks used to build this |

## Run it

```
npm install
npm run dev
npm test
```

## Not legal advice

Afterwards helps with standard forms. It says so when a case needs a lawyer.
