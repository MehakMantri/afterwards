# Editing a rulebook

- Never add or change a rule without an official source URL and the form's
  version date. If you cannot cite it, do not write it.
- Amounts are in rupees as integers. Thresholds are inclusive ("up to").
- Every combination of answers must reach exactly one route or "needs a lawyer".
- Banks differ. A bank-specific row overrides the generic RBI row; never edit
  the generic row to fit one bank.
